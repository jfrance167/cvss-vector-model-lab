# Decisions — October 5, 2026

- Original stdlib rather than candidate adoption. Red Hat's broader engine and
  optional-X cleaning do not fit this provenance contract; LGPL3+ source/corpus
  not copied. FIRST4 adds lookup/interpolation/browser surface. RESEARCH.md
  retains candidate/source limits.
- Archived 3.1 Base-only: eight declarations and inspectable fixed formulas.
  Scores are conditional on supplied metrics, not verified severity/risk.
- Fractions from literal decimal constants avoid binary floats and ambient
  Decimal context. Mathematical ceiling is frozen. Appendix A differs for
  arbitrary 4.000001 but not any of 2592 tested actual Base combinations. Any
  future Base discrepancy stops acceptance; never adjust oracle to match.
- All known validation precedes unsupported. Optional-X is an explicit
  unsupported declaration, not omission/default. Error output points to original
  immutable input and releases no stripped/partial score projection.
- Exact native identity before operations rejects metaclass/container/key
  hooks. API admission is not a sandbox for arbitrary Python code.
- Fixed stdio, exact write counts and flush. Failure detaches streams to
  preserve exit 3 on shutdown; no replacement file/device. No atomicity claim.
- Stage 1 froze 57 full expectations before scorer code. Literal numerical
  controls and independent hand calculations remain separate from finite
  properties and upstream tests. Mutant copies leave originals unchanged.
- Local/free research drafts failed or were rejected. Core arithmetic/oracles/
  security judgments unsuitable for that worker capability; Codex continued
  reviewed work without retry, provider switch or spending.
